# 頒布レジ

即売会で頒布物の売れた数・在庫・売上を正確に記録するための簡易POSです。
ブラウザだけで動作し、サーバーやアカウントは不要です。データは端末内にのみ保存され、電波がなくても使えます。

**公開URL**: https://bcno01.github.io/hanpu-pos/

## 主な機能

- **レジ**: 商品ボタンをタップしてカートに入れ、「会計」で確定。現金のみ対応で、預かり金額からお釣りを計算します
- **QRスキャン**: 商品ごとのQRをあらかじめ印刷しておき、カメラで読み取るだけでカートに入ります(タップ操作の入力ミスを減らせます)。同じQRをかざし続けても1回しか数えず、いったん外してかざし直すと次の1個になります。QRは商品の読み取り専用で、会計や取消などの操作は画面のボタンで行います(読み間違いで会計が走らないようにするため)
- **在庫管理**: 持ち込み数から頒布数・献本数を引いた残数を自動計算。残数が少ないと色が変わり、0で「完売」表示になります
- **セット割**: 「新刊+既刊で○○円」「同じ本を3冊で○○円」を登録しておくと、カートの中身に応じて自動で割引されます
- **献本・無料配布**: 売上に含めず、在庫だけ減らして記録できます(無配ペーパーや献本用)
- **履歴と取消**: 会計の取消・復活ができます。取消した会計は集計と在庫から外れます(記録自体は残ります)
- **集計**: 売上合計・会計件数・頒布数・客単価・商品別の頒布数/残数/売上を表示
- **時間別の推移**: 最初の会計から最後の会計までを、15分・30分・1時間ごとに区切って、売上または頒布数の推移をグラフで表示。「時間ごと」(棒グラフ)と「累計」(折れ線)を切り替えられ、棒や線をタップ(PCではマウスを乗せる)するとその時間帯の数字が出ます。「表で見る」で数字の一覧も確認できます。いちばん売れた時間帯も表示します
- **CSV出力**: 集計CSV(商品別)と明細CSV(会計ごと・商品別の数量つき)。UTF-8(BOM付き)でExcel/Numbersでも文字化けしません
- **バックアップ**: 全データをJSONで書き出し/読み込み
- **棚卸し**: 商品編集で「現在の残数」を実際に数えた値に直すと、持ち込み数が補正されます

## 使い方

1. 「設定」タブで商品(名前・価格・持ち込み数)を登録。必要ならセット割も登録
2. 商品をすべて登録したら、「設定」→「QRシートを表示・印刷」で印刷し、テーブルに置く(前日までに用意)
3. 「レジ」タブの「QRスキャンを開始」でカメラを起動し、売れた商品のQRをかざす。画面内ならどこに映っても読み取れます
   - 読み取れると確認音と画面上のメッセージで知らせます。商品の追加は「+1(計n)」、在庫切れは黄色の警告、未登録のQRは赤で表示されます
   - 読み間違えたときは、画面下のカート欄の「1つ戻す」で直前に入れた商品を1つ取り消せます(タップで入れた商品も対象)。商品ごとの「−」「+」や「クリア」も使えます
   - QRを使わず、商品ボタンのタップでも入力できます(QRが破れたとき用)
4. カート欄の「会計」ボタンで会計画面を開き、預かり金額を選んで「確定」。確定後の間違いは「履歴」タブで取消。会計直後は画面下のメッセージの「取り消す」でも戻せます
5. イベント中も後も、「集計」タブの「時間別の推移」で、どの時間帯によく売れたかを確認できる。イベント後は同じ「集計」タブからCSV(集計・明細・時間別)とバックアップを書き出す
6. 次のイベントの前に、「設定」→「会計データをリセット」で売上を空にして、持ち込み数を入れ直す

### QRについて

- QRの中身は商品ごとの固定コード(`P01`、`P02`…)です。商品名や価格を変えても、印刷済みのQRはそのまま使えます
- 商品を削除しても、そのコードは再利用しません(古いQRが別の商品として読まれないようにするため)
- 商品を追加したら、QRシートを開き直して印刷してください
- 会計画面を開いている間はカウントしません。閉じた直後に、映ったままのQRを二重に数えることもありません
- カメラは初回に許可が必要です。ホーム画面に追加したアプリからも使えます(iOS 13.4以降)

## インストール(PWA)

- **iPhone / iPad**: Safari で開き、共有メニュー →「ホーム画面に追加」
- **Mac**: Safari の共有メニュー →「Dockに追加」

**ホーム画面に追加して使ってください。** Safariのタブのまま使うと、しばらく開かなかったときにiOSがデータを消すことがあります。

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)、1ファイル(`index.html`)
- データは `localStorage` に保存(会計のたびに保存。直前の状態も予備として保持し、本体が壊れていたら自動で復元)
- 会計は追記のみ。取消はフラグを立てるだけで削除しないため、後から経緯を追えます
- QRの読み取りは [jsQR](https://github.com/cozmo/jsQR)(Apache-2.0)、生成は [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)(MIT)を `lib/` に同梱(CDNは使わず、オフラインで動作)。スキャンを開始したときと、QRシートを開いたときに初めて読み込みます。映像は端末内で処理するだけで、どこにも送信しません
- Service Workerでアプリ本体とライブラリをキャッシュ(`sw.js`)。オフラインで起動できます
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)

## 注意事項

- **データは端末内にしかありません。** ブラウザのデータ消去やアプリの削除で消えます。会場でこまめに(たとえば昼休憩と終了前に)バックアップを書き出すと安心です
- 現金専用です。キャッシュレス決済の記録・連携には対応していません
- 1台での運用を想定しています。複数端末の同期はありません
- 商品名・価格を途中で変えても、過去の会計は当時の名前・価格のまま集計されます
- 在庫が0でも会計は止まりません(確認ダイアログが出ます)。持ち込み数の数え間違いで売れなくなるのを避けるためです
